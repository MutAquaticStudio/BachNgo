        Automation phát hiện
          Tất cả hội thoại

            Thời điểm các lần chạy

              Lịch sử chat từ claude.ai

              1. Mở claude.ai ở tài khoản cũ → Settings → Privacy → Export data.
              2. Tải file .zip trong email Claude gửi về.
              3. Bấm Nhập file export… và chọn file .zip (hoặc conversations.json).

              Dữ liệu chỉ lưu trên máy này. Chọn một hội thoại để xem lại hoặc tiếp tục chat với nội dung đó.

              Task theo lịch trên claude.ai để lại nhiều hội thoại có cùng tin nhắn đầu. App gom chúng vào mục Automation phát hiện. Từ đó Claude đọc lại và tạo task tương ứng để chạy tiếp ở đây.
