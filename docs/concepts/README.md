# Concept (HTML tĩnh)

Ba trang concept đã trình bày với khách. Mở trực tiếp bằng trình duyệt (cần mạng để tải font và thư viện từ CDN).

- `01-concept-web.html`: ý tưởng "Sợi chỉ", nhận diện, chuyển động GSAP, kiến trúc ERPNext, lộ trình.
- `02-concept-uxui.html`: mô hình xem, hiểu, sở hữu; bốn thương hiệu subdomain; Three.js và GSAP làm được gì.
- `03-concept-admin-erp.html`: hai lớp giao diện quản trị, vai trò, năm màn hình mẫu, luồng đơn, mô hình dữ liệu, API.

Dữ liệu trong các trang là số mẫu, tên miền `bachngo.example` là chỗ giữ chỗ.
